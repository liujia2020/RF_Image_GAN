## 生产代码

| 文件 | 角色 | 注意 |
|------|------|------|
| `rf_learning_dataset.py` | 读 H5 → tensor | normalize=True 时三字段同除 scale |
| `rf_cache_builder.py` | H5 → fp16 cache | 默认 normalize=True，写入 scale.dat |
| `rf_cached_dataset.py` | 读 cache → tensor | restore_scale=True 乘回还原，强制 fp32 |
| `rf_cgan_models.py` | Envelope2DPatchDiscriminator | 2D，只看包络，y切片随机 |
| `rf_cgan_losses.py` | G_loss + D_loss | adv + struct(10.0) + carrier(0.5) |
| `rf_cgan_data.py` | StratifiedCategoryBatchSampler | 每 batch 含三类 |

## 关键约束

- **cache 生成**：normalize=True，三字段同除 scale → fp16
- **cache 读取**：fp16 → fp32 → 乘 scale → 返回 fp32（不能在 fp16 下乘！）
- **训练**：分层 batch 采样（BN 要求）
- **不抽样**：cache 验证 1500 个全量
