# 01 — 项目概述

## 1. 物理背景

### RCA 探头与正交平面波成像

Row-Column-Addressed (RCA) 阵列由两组正交排列的线阵组成——行阵元和列阵元各 128 个，
阵元沿长轴方向延伸覆盖整个探头边长（25.6 mm）。相比传统全采样矩阵阵列需要 N×N 个通道，
RCA 仅需 2N 个通道即可实现三维成像，

正交平面波（Orthogonal Plane-Wave, OPW）是 RCA 阵列的一种专用发射模式：
行阵元发射、列阵元接收（RC 模式），然后列阵元发射、行阵元接收（CR 模式），
两种模式互补叠加，使点扩散函数（PSF）从各向异性变为各向同性。

### DAS 重建：角度越多画质越好，但越慢

延时求和（Delay-and-Sum, DAS）是超声成像中最经典的重建算法。
对平面波成像而言，发射的倾斜平面波角度越多，相干复合后的图像信噪比和分辨率越高，
但计算量随角度数线性增长。

- **3 角度 DAS**（输入角度：3°, 38°, 73°）：帧率高，计算快，但图像散斑粗糙、分辨率差
- **33 角度 DAS**（均匀分布 1°~75°）：画质好，散斑均匀，但计算量是 3 角度的 11 倍

这就是本项目要解决的核心矛盾。

### 已发表论文基础

本项目基于已发表的 f-k 域重建方法（OPW-fk）[Liu et al., Chin. Phys. B]。
该方法在频域-波数域处理平面波数据，将计算复杂度从 O(PNMH²) 降至 O(PMH²log(MH))，
在 MATLAB CPU 平台上实现了约 11 倍加速，同时 FWHM 改善 2.19%、CR 改善 12.96%、CNR 改善 17.84%。

## 2. 项目目标

用深度学习网络把**延时对齐的 3 角度 RF 张量**直接映射为接近 **33 角度 DAS** 画质的复数 RF volume。

具体而言：
- **输入**：3 角度的 RF 张量，形状 [1536, 64, 32, 32]（128 通道 × 3 角度 × 4 分量）
- **输出**：复数 DAS volume，形状 [2, 64, 32, 32]
- **目标**：散斑纹理逼真（DAS-like speckle）、相干结构保持（血管壁、仿体线靶不丢失）、
  全卷拼接无缝

## 3. 与已发表论文的关系

| | CPB 论文 (OPW-fk) | 本项目 (RF-cGAN) |
|---|---|---|
| **探头** | 同一个 RC6gV RCA | 同一个 |
| **平台** | Vantage 256 | 同一个 |
| **问题** | 用什么算法重建更快更好 | 能否用深度学习从低角度预测高角度画质 |
| **方法** | f-k 域迁移（解析法） | 条件 GAN（数据驱动） |
| **baseline** | OPW-DAS (3角度 + 33角度) | 同左；3角度→baseline，33角度→label |
| **加速策略** | 算法级（降低复杂度） | 推理时只用 3 角度（采集时间 = 原来的 1/11） |

两台设备同一套硬件，本项目可以看作是 CPB 论文在深度学习方向上的延伸：
**用 3 角度的采集时间，获得接近 33 角度的画质。**

## 4. 技术路线

```
回归模型 (TinyResidualRFNet)
  → 代理指标通过，人眼验证失败：散斑糊、线靶丢失
  → 根因：L1 回归趋向条件均值，产不出随机散斑
  → [2026-06] 冻结为负结果

条件 GAN (当前主线)
  → 生成器：残差 RF-到-复数 volume
  → 判别器：2D PatchGAN 在包络上
  → 损失：对抗 (hinge/LSGAN) + 结构保真 (lowpass env L1) + 逐像素 (L1)
  → 目标：GAN 出散斑 + 保真锁结构
```
