# 06 — 关键发现与教训

> 这篇是论文 Discussion 的素材库。每个发现标注了对应论文论点。

---

## 1. 回归范式失败分析 → 论文 Discussion：为什么 L1 不够

**发现**：WideDeep+SSIM+crop8 回归模型在代理指标上大幅改善，但 NIfTI + 3D Slicer 人眼验证失败。

**根因**：L1 损失数学上趋向条件均值，均值回归压扁了随机散斑纹理（mush）+ 稀疏强反射体（点靶）被对冲压平。

**证据链**：phantom 线靶 label 有、pred 无（已确认）→ 组织 speckle 形态差 → 代理指标改善但人眼否决。

**教训**：回归范式天花板是原理性的，不是调参能突破的。散斑是不可约的随机成分。

> 论文论点：L1 regression converges to conditional mean → destroys speckle → need adversarial generation.

---

## 2. 缝根因：InstanceNorm → BatchNorm → 论文 Discussion：归一化对拼图的影响

**发现**：InstancNorm3d 推理时使用 per-patch 自身统计（track_running_stats=False），导致相邻 patch 统计不连续，产生 seam。

**验证**：13 卷 dense64 诊断，BN 替换 IN 后 seam 从 1.46→0.535（-63%），patch complex improvement 从 47.32%→56.85%。

**教训**：
- 缝不是网络独自产物（baseline 自身也有 2.99x 边界跳变，不过网络）
- 大感受野没有额外压缝力（UNet 1.53 vs Tiny 1.46）
- IN 改 track_running_stats 是错误方案（仍为 instance-level），正解是换 BN

> 论文论点：InstanceNorm causes patch-boundary statistical discontinuity → BatchNorm fixes it.

---

## 3. 各向异性物理约束 → 论文 Methods

**发现**：RCA-OPW 网格轴向 0.0362mm、横向 0.2mm，比例 1:5.5。网络下采样必须在 x/y 做、z 保守。

**影响**：显示 aspect ratio 必须按物理间距设，否则视觉判读被误导。低通滤波 sigma_zyx=(6,3,3) 正是基于散斑自相关 FWHM 设计的。

---

## 4. 散斑自相关 FWHM → 论文 Methods：低通滤波参数设计依据

**发现**：Phase 0 测量 DAS label 散斑自相关 FWHM：z≈6 voxels, x≈3 voxels, y≈3 voxels。SNR≈2.0~2.2（接近 Rayleigh 理论值）。

**用途**：直接决定 `AnisotropicGaussianLowpass3D` 的 sigma_zyx=(6,3,3)，struct loss 只看组织结构不看散斑纹理。

---

## 5. fp16 溢出与 scale 机制 → 工程经验

**发现**：float32→fp16 直接转换，label 可达 256,494（3.9x fp16 上限），377/1500 样本溢出。

**根因**：scale 机制存在但未启用（normalize=False）。修复：normalize=True，三字段同除 scale。

**教训**：生成端和 reader 端必须配对修改，任一端不对称会静默错。抽样不够漏 phantom 9 个样本，全量才抓出。

---

## 6. 视觉判读被显示参数欺骗 → 方法论

**发现**：dB 共享 ref 会让两个完全不同的图看起来一样，曾导致"模型退步"误判。边界跳变指标（客观量化）纠正了视觉误判。

**教训**：视觉和数值冲突时，以客观量化指标仲裁。不被 dB ref、aspect、db_min 骗。

---

## 7. patch 级指标对拼图缝盲 → 方法论

**发现**：patch 级 test improvement（L1、SSIM）几乎不反映拼图 seam。UNet val best 优于 Tiny，但拼图边界跳变更差。

**教训**：任何模型在宣布"可用"前必须做 full-volume 拼接验证。patch 级指标不能代替。


## 8. AMP 与大幅值数据冲突 → 工程经验

**发现**：真实物理幅值（7万级）下，平方操作  远超 fp16 上限。
AMP 自动混合精度把中间运算降到 fp16 导致 inf。

**教训**：cache 用 scale 解决了存储 fp16 溢出，但计算图里 AMP 又引入 fp16。
同一个 fp16 上限，不同地方咬人。数据回到真实尺度后，任何 fp16 路径都要警惕平方/乘积操作。

**修复**：关闭 AMP。显存占用从约 2.55GB 略增到 2.78GB，RTX 5060 完全可承受。


## 9. struct-adv 量纲失衡 → 论文 Discussion：损失设计的核心挑战

**发现**：Phase2a 50 epoch 训练，G_struct_weighted=43,135 vs G_adv_weighted=0.999。
比例 43,000:1，对抗损失形同虚设。

**根因**：struct 在原始数据空间计算（值域几万），adv 是概率损失（值域 0~1）。
两者量纲不在一个尺度上。struct 天然比 adv 大几个数量级。

**影响**：网络退化回 struct 主导的回归模式——adv 该管的精细散斑纹理根本没被训练到。
pred≈baseline，判别器几乎分不清真假。

**修复方向**：把 struct 改为尺度无关的相对量（pred/label 各归一化后再比较），
让 struct 和 adv 落在同一量级。

**修复**：struct 归一化 — s = mean(|env(label)|) + 1e-8，pred 和 label 同除 s。数学上 struct_new = struct_old / s。Proma 独立验证：三类样本最大相对差异 1.08e-7（float32 精度），等价性确认。struct_new 从 43,135 降至 0.98（O(1)），与 adv（~1.0）落在同一量级。struct:adv 比例问题已解决。

**教训**：多损失联合训练时，每个损失的**量纲**比**权重系数**重要得多。
一个不对的量纲不是靠调权重能修复的。


## 10. carrier 主导 — struct 归一化的连锁发现 → 论文 Discussion：损失设计的核心挑战（续）

**发现**：struct 归一化后 struct:adv=1:1 比例健康，但 carrier（复数 L1，lambda=0.5）未经归一化，在原始物理空间计算值域 ~6100，加权后 ~3050，占 G_total 的 99.9%。struct+adv 加起来不到 0.1%。

**证据**：Phase2a normstruct v1，epoch 50：
- G_carrier_weighted = 3,049 (99.93%)
- G_adv_weighted = 1.00 (0.03%)
- G_struct_weighted = 0.98 (0.03%)

**根因**：与 struct 相同的量纲问题 — carrier 在原始数据空间计算（pred 幅值可达 280,000），而 struct 归一化只修了 struct，carrier 原封不动。struct 归一化的成功正好暴露了 carrier 是下一个瓶颈。

**影响**：
- 网络实质上仍被复数 L1 回归驱动 — 与回归范式的 mush 根因同源。
- 三类 pred_SNR 持续下降（carotid 1.02→0.96, phantom 1.54→1.41），符合 carrier 主导→均值回归倾向。
- D_fake_score 卡在 0.500 → adv 梯度无效 → 训练后半程 ≈ carrier 单人驱动。
- 判别器过早均衡可能与 carrier 主导有关：carrier 推着 pred 往 label 均值走，生成样本缺乏对抗多样性，D 轻松达到均衡。

**修复方向**：对 carrier 做相同的 label 派生标量归一化，使 carrier 也落入 O(1)，与 struct 和 adv 在同一量级。struct+carrier 双归一化后重新训练。

**教训**：多损失联合训练中，解决了最显眼的量纲问题后，次大的会立刻成为瓶颈。所有在原始物理空间计算的损失项（struct、carrier、未来可能的 perceptual loss 等）都需要逐一归一化，不是修一个就够。

## 11. carrier 功能不可替代 — 消融实验确认 → 论文 Discussion：损失设计中 carrier 的必要性

**发现**：关掉 carrier（lambda_carrier=0）后 G 几乎不学。19 epoch G_struct 仅下降 1.4%（1.10→1.09），G_adv 反而微涨。pred ≈ baseline，无明显脱离输入的趋势。

**根因**：三项损失各管一层物理尺度——struct 管大尺度组织（低通包络），adv 管纹理分布真假，carrier 管逐像素 A-line 物理一致性。struct+adv 两层的覆盖范围存在盲区：struct 的 lowpass 滤掉了 carrier 承载的高频像素级约束，adv 只管分布不管位置。关掉 carrier 后高频像素级指导信号完全缺失。

**证据**：三实验横向对比——
- v0（无归一化）：struct 主导 43k:1，有学习信号但方向错（量纲失衡）
- v1（struct 归一化）：carrier 主导 99.9%，G_struct 同期下降显著（1.10→0.98，-10.9%）
- v2（关 carrier）：struct:adv=1:1 完美比例，但 G_struct 仅下降 1.4%

v1 的 G_struct 降幅反而远大于 v2，说明 carrier 虽在原始空间但确实提供了有效的底层驱动。

**影响**：
- carrier 不可省略。不是"carrier 抢戏太多不如关掉"，而是"carrier 抢戏是因为它没归一化，但它本身是必需的"。
- D 本身很弱：D_real_score 仅 0.73（健康值应接近 1.0），不是 D 碾压 G 的问题。
- 方向明确：carrier 必须保留 + 归一化，而非继续在"去掉某个损失"上试。

**教训**：多损失联合训练中，当某个损失项主导时，不应直接关掉它来测试"是否多余"——它主导可能是因为量纲不对，而非功能多余。应先用归一化将其拉到 O(1)，再在公平的条件下评估其必要性。这次的实验顺序恰好证明了这一点：先归一化主导项，再评估其余项。

> **后续升级（2026-06-08 三方讨论）**：v2 的"网络不学"有两种解释——A: carrier 是唯一有效的梯度源；B: 对抗机制坏了，carrier 恰好是剩下唯一没坏的信号。v2 的实验事实本身不能区分 A 和 B。结合三轮 D_fake=0.50、D_real=0.73、pred 从未离开 baseline，B 的可能性更大。carrier 的定位从"不可替代的支柱"升级为"当前坏判别器下唯一在干活的拐杖——能用但方向可疑"。
> 论文论点细化：carrier removal experiment demonstrates that under a non-functional discriminator, the only remaining gradient signal comes from the pixel-wise L1 term — but this does not prove carrier is inherently irreplaceable, only that the adversarial path was never alive.

## 12. 对抗机制三轮从未生效 → 论文 Discussion：为什么对抗训练在设计良好的损失下仍可能失败

**发现**：三轮 Phase 2a 实验（v0/v1/v2），无论损失权重如何配置、量纲比例如何变化，对抗损失从未提供有效梯度。D_fake_score 三轮均为 0.500（随机猜测），G_adv 三轮均为 ~1.0（恒定），D_real_score 仅 0.73（对真样本也不自信）。

**根因分析**：
- 这不是"损失量级失衡"的问题——v2 证明了即使 struct:adv=1:1 完美比例，对抗仍然空转。
- D_real=0.73 提示判别器本身学习能力不足——一个不能自信识别真样本的判别器，无法为生成器提供有意义的对抗梯度。
- 可能原因：① 判别器架构太弱（2D PatchGAN 可能不足以捕捉 3D 散斑统计）；② 线性大动态范围下判别器被强点主导，学不到弱信号区的纹理统计；③ 生成器任务太难（从 3 角度 RF 预测 33 角度画质），D 轻松区分→过早均衡。

**影响**：
- 对抗机制是生成散斑纹理的唯一途径（struct 只管大尺度结构，carrier 只管像素回归）。对抗不工作 = 散斑永远学不到 = pred 永远贴 baseline。
- "先修损失量级、再修对抗"的递进策略由此确立：在损失量级还失衡时谈"判别器强不强"无意义；但修完量级后如果对抗仍空转，问题就在判别器本身。

**教训**：多损失 GAN 训练中，"对抗不起作用"可能比"损失量级失衡"更隐蔽、更致命。量级失衡至少会反映在数值上（一项占 99%），对抗空转则表现为 D_fake 恒 0.5、G_adv 恒 1.0——表面数字正常，实际完全失效。D_real_score 是诊断判别器健康的关键指标，不应被忽略。

> 论文论点：Three-round consistent adversarial failure (D_fake=0.500, D_real=0.73) suggests the discriminator architecture may be the bottleneck, not loss weighting — a "clean baseline" strategy is needed to isolate the root cause.

## 13. 线性归一化 vs log 压缩 for 复数超声数据 → 论文 Methods：数据预处理策略

**发现**：用户观察到 3D-ARCGAN 在 log 压缩后的图像上成功训练，而当前 RF cGAN 在线性大幅值空间训练。讨论后确认：对复数 RF 数据，"除 label 派生标量"的线性归一化比 log 压缩更合适。

**关键区分**：
- RF 输入（震荡信号，有正有负）不能 log 压缩，且动态范围并不夸张（mean_abs~261）——输入端不是问题
- struct 和 adv 已在包络上计算——离 B-mode 只差一个 log，动态范围已被相当程度均衡
- 真正踩在原始复数大值（~280,000）上的只有 carrier 一项

**为什么线性归一化比 log 压缩更适合**：
- log 是非线性变换：改变损失地形，对梯度的缩放不均匀，且对复数正负/相位难处理
- 除标量是线性缩放：保留梯度方向、天然兼容复数、等价地压缩动态范围
- 对复数重建任务，"除 label 派生标量"在效果上等价于 log 压缩的目的（让强弱可比），但避开了 log 对复数的不兼容

**影响**：
- 不需要整体换到 log/压缩空间训练——当前的"逐项归一化"路线就是正确的
- 用户的归一化方案不仅是"给损失打补丁"，它本身就是一种对复数友好的数据预处理范式
- carrier 归一化是最后一块拼图：struct 已归一化，adv 本来就是概率损失（0~1），carrier 归一化后三项全部 O(1)

**教训**：超声成像中 log 压缩是 B-mode 显示的标准操作，但对深度学习训练而言，"是否压缩"取决于数据形态——实数图像适合 log，复数 RF 适合除标量。不应机械套用图像域的成功经验到 RF 域。

> 论文论点：Linear scalar normalization (divide by label-derived scale) serves as a complex-friendly alternative to log compression for raw RF data — achieving dynamic range equalization while preserving phase and gradient linearity.
