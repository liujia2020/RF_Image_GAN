```mermaid
graph LR

    PHYS --> REG["❌ 回归范式<br/>WideDeep+SSIM<br/>L1→条件均值<br/>散斑mush + 线靶丢<br/>Slicer否决<br/>发现 #1"]

    style REG fill:#fdd
    style GAN fill:#dfd
```

- RCA-OPW 轴向 0.0362mm / 横向 0.2mm，比例 1:5.5
- 下采样在 x/y 做、z 保守
- 低通 sigma_zyx=(6,3,3) 基于散斑 FWHM 设计
- 回归天花板是原理性的，不是调参能突破的

## 第3层：损失函数 — 往哪个方向学（踩坑最密集）

### 复数空间阶段（Phase 2a，已废弃）

> `G = λ_adv·adv(LSGAN) + λ_struct·struct(低通包络L1) + λ_carrier·carrier(复数L1)`

```mermaid
graph TD
    START["第1层选复数 GT<br/>值域 28 万"]
    
    START --> V0["v0: 无归一化<br/>struct 43,135 : adv 1.0<br/>43,000:1 量纲失衡<br/>发现 #9"]
    V0 --> V1["v1: struct归一化<br/>✅ struct→O1,1:1<br/>❌ carrier占99.9%<br/>发现 #10"]
    V1 --> V2["v2: 关carrier<br/>G几乎不学<br/>D_real=0.73<br/>发现 #11"]
    V2 --> V3["v3: carrier归一化<br/>✅ 三损失O1<br/>❌ 对抗仍空转<br/>D_fake=0.50不变<br/>发现 #12"]
    
    V3 --> CONCLUSION["铁证: 损失量级<br/>被永久排除<br/>病根在判别器<br/>发现 #14"]

    START -->|"根因"| START

    style V0 fill:#fdd
    style V1 fill:#fdd
    style V2 fill:#fdd
    style V3 fill:#fdd
    style CONCLUSION fill:#ffd
```

**四轮消融烧了 ~25 GPU 小时，每轮只动一个变量。**
结论：量纲问题已全部解决，但对抗从未通电——判别器太弱（D_real=0.73）。
