## `rf_learning_dataset.py` — HDF5 读取器

**角色**：管线 ④，把 MATLAB 写的 HDF5 转为 PyTorch 可用 tensor

**核心逻辑**：

```python
RFLearningDataset(root_dir, normalize=False/True)
  → .rglob("*.h5") 搜集所有文件
  → __getitem__: 读 F_RC/CR_real/imag + DAS → transpose/reshape → torch.Tensor
```

**关键设计**：

- **normalize 开关**：`True` 时 scale=max(|label|)，三字段同除 scale；`False` 时 scale=1.0
- **维度重排**：H5 `[角度,通道,Y,X,Z]` → transpose → `[Z,X,Y,通道,角度]` → reshape → `[1536,Z,X,Y]`
- **文件级 split**：sorted(rglob) 排序后用前 N 个文件，同一文件的所有 patch 在同一 split

> ⚠️ **踩坑**：`normalize=False`（默认）导致 scale=1.0，fp16 溢出根因。Cache 生成时必须 `normalize=True`。

## `rf_cache_builder.py` — Cache 生成器

**角色**：管线 ⑤，1500×H5 → 6 个连续二进制 memmap

**核心逻辑**：

```python
build_split_cache(root_dir, cache_dir, split, normalize=True):
  dataset = RFLearningDataset(root_dir, normalize=True)
  for idx in range(n_samples):
      item = dataset[idx]
      s = item["scale"]                                    # max(|label|)
      input_mm[idx]    = (item["input"]    / s).fp16()
      label_mm[idx]    = (item["label"]    / s).fp16()
      baseline_mm[idx] = (item["baseline"] / s).fp16()
      scale_mm[idx]    = s.float()
  np.savez_compressed("meta.npz", normalize=True, ...)
```

**关键设计**：

- **normalize=True（修正后）**：转 fp16 前先除 scale，防止溢出
- **三个字段同除一个 scale**：保持 input/label/baseline 相对比例不变
- **memmap w+ 模式**：创建文件时不填数据，逐行写入后 flush
- **verify_split_cache()**：自带全量验证函数

> ⚠️ **踩坑**：旧版 normalize=False，直接 .astype(fp16)，scale 只存不用。→ fp16 溢出。

## `rf_cached_dataset.py` — Cache 读取器

**角色**：管线 ⑥，训练时以最高 I/O 效率读 cache

**核心逻辑**：

```python
RFCachedDataset(cache_dir, return_fp16=False, restore_scale=True):
  # __init__: 打开 memmap（不加载数据）
  self.input = np.memmap("input.dat", dtype=fp16, mode="r")
  self.scale = np.memmap("scale.dat", dtype=fp32, mode="r")
  
  # __getitem__: 读 fp16 → 转 fp32 → 乘 scale 还原
  data = np.array(self.input[idx], dtype=np.float32)
  if restore_scale:
      data = data * self.scale[idx]
  return {"input": ..., "label": ..., "scale": ...}
```

**关键设计**：

- **还原时序**：fp16 memmap → float32 → 乘 scale（不能 fp16 下乘！会重新溢出）
- **强制 fp32 返回**：归一化 cache 下忽略 `return_fp16=True`
- **page cache 依赖**：epoch 1 冷读慢，epoch 2+ 全在内存

> ⚠️ **踩坑**：旧 reader 没有 restore_scale 逻辑。生成端加缩放、reader 不加还原 → 训练读到缩小值，静默错。

## `rf_cgan_models.py` — 判别器

**角色**：训练时判断生成器的输出是否像真实 DAS

**方法**：Envelope2DPatchDiscriminator（2D PatchGAN，只看包络）

**核心逻辑**：

```
输入:  [B, 2, Z, X]
       通道0 = 候选或 label 的包络 y-slice
       通道1 = baseline 的包络 y-slice（条件）

结构:  Conv2d(2→64) → Conv(64→128) → Conv(128→256) → Conv(256→1)
       每层: k4s2p1 + LeakyReLU(0.2) + InstanceNorm2d

输出:  [B, 1, H, W] patch 真/假分数
```

**关键设计**：

| 决策 | 原因 |
|------|------|
| 2D 而非 3D | 省显存，y-slice 已有足够结构信息 |
| 只看包络 | 散斑纹理在包络上，相位对判别纹理无帮助 |
| baseline 作为条件 | D 知道输入 RF 长这样，不被结构和预测差误导 |
| y 切片随机 | 每次 iteration 随机选 Y 层，防止只在某层过拟合 |

## `rf_cgan_losses.py` — 损失函数（科学核心）

**角色**：训练时计算 G 和 D 的损失，定义"什么是好输出"

**方法**：三组件生成器损失 = 对抗 + 结构保真 + 载波约束

**核心逻辑**：

```
G_loss = 1.0 × adv + 1.0 × struct + 0.5 × carrier
          ↑            ↑              ↑
        LSGAN       低通包络L1     复值L1
        (出散斑)    (保结构)      (锁物理)
```

| 项 | 权重 | 含义 | 作用 |
|----|------|------|------|
| `adv` | 1.0 | LSGAN 对抗：MSE(D(pred_env), 1) | 逼 D 无法分辨真假 → 散斑纹理 |
| `struct` | **1.0** | 归一化低通包络 L1 | **主保真项**，锁定大尺度组织结构 |
| `carrier` | 0.5 | 复值 L1(pred, label) | 微弱逐像素约束，防止物理上不可能的 A-line |

**struct 归一化实现**（2026-06-08）：

```python
# s = mean(|env(label)|) + 1e-8  — 从 label 派生的单一标量
# pred 和 label 同除 s，线性的高斯低通保证等价性：
# LP((pred_env - label_env) / s) == LP(pred_env - label_env) / s
struct_scale = label_env.detach().abs().mean() + 1e-8
struct_delta = lowpass((pred_env - label_env) / struct_scale)
struct = torch.mean(torch.abs(struct_delta))
```

**关键设计**：
- **同除一个尺度**：pred 和 label 共用 label 派生的 s，不是各除各的（后者会抹掉绝对幅值信息）
- **数学等价性**：struct_new = struct_old / s，Proma 独立验证三类样本，max rel_diff 1.08e-7（float32 精度）
- **保留 unnormalized 追踪**：`struct_unnormalized = struct * struct_scale`，用于监控物理空间的真实结构损失
- **struct_scale 恒定**：s 只取决于 label，训练中不变（label 固定），每个 batch 的 s 可能略有不同

**低通参数**：`sigma_zyx = (6, 3, 3)` voxels，来自 Phase 0 DAS label 散斑自相关 FWHM 测量。
滤掉散斑（高频随机纹理），保留组织结构（低频大特征）。
struct loss 只约束"解剖结构不变形"，不要求"散斑纹理一模一样"。

**判别器损失**：标准 LSGAN — 真样本→1，假样本→0。

> ⚠️ **踩坑**：回归范式只用了 L1，等价于 struct 和 carrier 但没有 adv。
> 散斑被 L1 的均值回归压扁成 mush。struct+carrier 给保真、adv 给出散斑，三个缺一不可。

## `rf_cgan_data.py` — 分层类别采样器

**角色**：保证每个训练 batch 都包含 carotid、muscle、phantom 三类

**方法**：StratifiedCategoryBatchSampler

**核心逻辑**：

```python
每个 batch: [carotid_sample, muscle_sample, phantom_sample]
batch_size = 3（每类 1 个 × 3 类）
```

**关键设计**：

- **BatchNorm3d 需要混合 batch**：纯单类 batch 会让 BN 统计在类别间振荡
- **这是缝根因的延续**：BN 替代 IN 后解决了 per-patch 统计不连续，但对 batch 构成敏感

## 关键设计决策表

| 决策 | 原因 | 日期 |
|------|------|------|
| D 是 2D | 省显存，pilot 够用 | 2026-06 |
| D 只看包络 | 散斑纹理在包络上，相位无用 | 2026-06 |
| G 用 BatchNorm3d | IN 导致 patch 间统计不连续 → seam | 2026-05 |
| 分层 batch 采样 | BN 需要混合类别分布 | 2026-06 |
| struct 归一化 | struct→O(1)，与 adv 等比，Proma 独立验证等价性确认 | 2026-06-08 |
| struct weight=1.0 | 归一化后无需高权重，struct:adv=1:1 | 2026-06-08 |
| carrier weight=0.5 | 只需微弱约束，太重回到 mush | 2026-06 |
| fp16 cache + fp32 算 | I/O 省一半带宽，计算不损失精度 | 2026-05 |
| num_workers=0 | 多进程 + memmap 兼容问题 | 2026-05 |
| normalize=True (cache) | fp16 溢出修复 | 2026-06-07 |
| reader 强制 fp32 返回 | 还原后值 >65504 | 2026-06-07 |
