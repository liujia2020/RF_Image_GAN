## 关键认知升级（v2 后续三方分析，2026-06-08）

### "除标量归一化"即线性动态范围压缩

用户的"除 label 派生标量"归一化方案，数学上等价于一种**线性动态范围压缩**——将 carrier 从 28 万值域拉到 O(1)，目的和 log 压缩相同（让强弱可比）。区别：log 是非线性（改变损失地形、对复数正负/相位难处理），除标量是线性缩放（保留梯度方向、天然兼容复数）。对复数重建任务，除标量归一化比 log 压缩更合适。

### carrier 定位升级

v2 消融实验排除了"关 carrier、单靠 adv"的路线，但**不等价于证明 carrier 本身不可替代**。v2 的"网络不学"有两种解释：
- A：carrier 是唯一有效的梯度源
- B：对抗机制坏了，carrier 恰好是剩下唯一没坏的信号

v2 的实验事实不能区分 A 和 B。结合三轮 D_fake 恒定 0.50、D_real=0.73、pred 从未离开 baseline 的事实，**B 的可能性更大**。carrier 的定位从"不可替代的支柱"升级为"当前坏判别器下唯一在干活的拐杖——能用但方向可疑（逐像素 L1 往 mush 拽）"。

### 对抗机制空转：比损失量级更底层的病根

三轮实验无论损失怎么配（struct 主导/carrier 主导/五五开），对抗从未生效：
| | D_fake_score | G_adv | 对抗有效？ |
|---|---|---|---|
| v0 (无归一化) | 0.50 | ~1.0 | 否 |
| v1 (struct归一化) | 0.50 | ~1.0 | 否 |
| v2 (关carrier) | 0.50 | ~1.0 | 否 |

D_real=0.73（健康值应接近 1.0）是直接证据：判别器本身就很弱、学不动。一个学不动的判别器，意味着对抗损失从一开始就是空转的。这被判断为**可能比损失量级更底层的病根**，将在干净基线建立后暴露并验证。
