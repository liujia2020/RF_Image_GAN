## 路线转向：复数→B-mode + 纯监督（2026-06-09，重大方向决策）

### 背景：Phase 2a 四轮消融的终点

四轮递进消融（v0→v1→v2→v3）永久排除了"损失量级失衡"这个解释。对抗在干净基线下仍然空转（D_fake=0.50, D_real=0.73, G_adv=1.0）。病根锁定在判别器。

但 Claude 没直接让修判别器，而是先做了文献调研——因为"对抗从未工作过"可能不是判别器的问题，而是"对抗+复数线性空间"这条路本身就有问题。

### 文献调研结论：三条致命差异

Claude 搜索了 RF→超声成像的深度学习文献，发现我们和主流做法有三个关键差异：

|  | 我们五轮的做法 | 文献主流 |
|---|---|---|
| 训练空间 | 复数线性，动态范围 28 万 | B-mode/包络，log 压缩+归一化 |
| 主力损失 | 想让 adv 主导 | L1/SSIM 主导（权重 10~100） |
| 对抗角色 | 当核心，纠结它不起来 | 小配角，甚至不用 |

关键证据：
- DL-DCL 论文观察到 GAN 在此任务上训练不稳定，而纯监督方法稳定收敛且效果 competitive
- 几乎所有 PWC/compounding 工作都在 B-mode/包络空间训练
- pix2pix 超声、WSRGAN 等都是 L1/SSIM 主导 + 对抗辅助（λ=10~100）
- "少角度→多角度质量"是成熟方向（plane wave compounding），GAN 被用来做这个，但做法和我们相反

### 决策：换战场

决定把战场从"复数空间 + 对抗攻坚"搬到"B-mode 空间 + 强监督"：

1. **训练空间换到 B-mode（包络+log压缩+归一化）**：一举消灭五轮所有动态范围麻烦
2. **损失改成 L1+3D-SSIM 纯监督为主，对抗先拿掉**：文献反复验证的成功组合，用户 3D-ARCGAN 也验证过
3. **输入仍是 3 角度 raw RF，推理仍不重建**：项目核心价值（端到端、跳过 DAS）完整保留
4. **代价：放弃相位信息**：当前 B-mode 目标无所谓，将来做 Doppler 需回到复数

### 关键技术细节

**B-mode 五步标准**（来自用户 MATLAB 代码，与论文一致）：
```
① 取包络:   abs(复数)             复数 → 幅值
② 归一化:   除以全局 REF           幅值 → 0~1（所有样本同一把尺子）
③ log压缩:  20·log10(... + 1e-12) → dB
④⑤ 截断:   限制在 [-60, 0] dB → 映射到 [0,1]
```

**全局 REF 的选择**：不能直接用全局绝对 max（会被极端离群点绑架）。用稳健高分位数 64407.58 做统一参照，既统一又不被离群点绑架。phantom 因此偏暗（均值 0.40 vs carotid/muscle 0.57/0.58），这是全局参照的自然代价，本轮先接受。

**MS-SSIM 尺寸坑**：数据 [64,32,32] 最小边 32，标准 5 尺度 MS-SSIM 连续减半 32→16→8→4→2，到第 5 尺度窗口不够大，直接报错。改单尺度 3D SSIM（window=7），稳且覆盖核心需求。

## 关键认知升级（v2 后续三方分析，2026-06-08）

### "除标量归一化"即线性动态范围压缩

用户的"除 label 派生标量"归一化方案，数学上等价于一种**线性动态范围压缩**——将 carrier 从 28 万值域拉到 O(1)，目的和 log 压缩相同（让强弱可比）。区别：log 是非线性（改变损失地形、对复数正负/相位难处理），除标量是线性缩放（保留梯度方向、天然兼容复数）。对复数重建任务，除标量归一化比 log 压缩更合适。

### carrier 定位升级

v2 消融实验排除了"关 carrier、单靠 adv"的路线，但**不等价于证明 carrier 本身不可替代**。v2 的"网络不学"有两种解释：
- A：carrier 是唯一有效的梯度源
- B：对抗机制坏了，carrier 恰好是剩下唯一没坏的信号

v2 的实验事实不能区分 A 和 B。结合三轮 D_fake 恒定 0.50、D_real=0.73、pred 从未离开 baseline 的事实，**B 的可能性更大**。carrier 的定位从"不可替代的支柱"升级为"当前坏判别器下唯一在干活的拐杖——能用但方向可疑（逐像素 L1 往 mush 拽）"。

### 对抗机制空转：比损失量级更底层的病根

三轮实验无论损失怎么配（struct 主导/carrier 主导/五五开），对抗从未生效：
| | D_fake_score | G_adv | D_real | 对抗有效？ |
|---|---|---|---|---|
| v0 (无归一化) | 0.50 | ~1.0 | — | 否 |
| v1 (struct归一化) | 0.50 | ~1.0 | — | 否 |
| v2 (关carrier) | 0.50 | ~1.0 | 0.73 | 否 |
| v3 (三损失O(1)) | 0.50 | ~1.0 | 0.73 | 否 |

D_real=0.73（健康值应接近 1.0）是直接证据：判别器本身就很弱、学不动。一个学不动的判别器，意味着对抗损失从一开始就是空转的。**v3 干净基线已确认：损失量级不是问题。四轮对抗空转，病根在判别器。**
