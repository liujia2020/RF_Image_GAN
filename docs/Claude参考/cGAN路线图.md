# cGAN 计划

最后更新: 2026-06-04 21:32:24 +08:00

## 1) 当前判决

回归线已冻结为负面结果。WideDeep+SSIM+crop8 改善了代理指标，但 NIfTI + 3D Slicer 人类审查否决了它：仿体线靶丢失、组织散斑呈糊状。项目现在转向配对条件 GAN 家族。

本文档仅为计划记录，本身不授权训练。

## 2) 目标

用神经网络将延时对齐的多角度 RF 张量直接映射到与 DAS 相当的图像质量输出，包括逼真的组织/仿体散斑和保持的相干结构。

目标不是"更好的代理指标"，而是基于 `docs/VALIDATION_PROTOCOL.md` 验证门禁的与 DAS 视觉和定量一致。

## 3) 为什么选配对条件 GAN

数据集是配对的：RF 输入对应 DAS label。这使配对条件 GAN 成为合适的家族：

- 生成器以 RF 输入和可选的 baseline 为条件。
- 判别器判断输出在同条件下是否像 DAS。
- 保真度损失将输出约束在此 RF 帧上，防止幻觉。

无条件 GAN 不是重建。CycleGAN 丢弃了配对监督，仅当没有配对数据时才是后备方案。

## 4) 第一阶段范围

主要范围：

- 组织和仿体逼真散斑。
- 配对 RF 到 DAS 重建。
- 全卷拼接兼容。
- 验证门禁产物：NIfTI、标准指标、固定对比图。

不在第一阶段范围：

- `simu_point` 作为主训练类别。
- 扩散模型，因为本地 8GB GPU 上 3D volume 训练目前不现实。
- 任何没有人类 Slicer 审查的质量声称。

点靶作为健全性检查和未来分支目标，不是第一个 GAN 目标。

## 5) 回归线可复用资产

保留并复用：

- `RFLearningDataset`、`RFCachedDataset` 和 cache 构建逻辑。
- BN 归一化教训和启动自检纪律。
- 拼接、crop8/halo、覆盖检查。
- NIfTI 导出和验证门禁纪律。
- 回归 checkpoint 作为 baseline 和负面结果证据。

不作为最终目标复用：

- 纯 L1/SSIM 回归作为主训练范式。
- 仅代理指标验收。

## 6) 候选架构问题

生成器候选：

- 从保守的残差 RF-到-复数 生成器开始。
- 保持 shape 契约：`input [B,1536,Z,X,Y]`，`baseline [B,2,Z,X,Y]`，输出 `[B,2,Z,X,Y]`。
- 先使用 AMP 和小 batch；仅局部 smoke test。

判别器候选：

- 在包络或 dB 包络上的 PatchGAN 式判别器。
- 条件判别器接收 baseline/包络或低通道条件，最初不接收完整 1536 RF。
- 可先尝试 2D 切片判别器节省内存，再尝试 3D patch 判别器（若可行）。

损失候选：

- 保真度：复数 L1、包络 L1，可选小权重 SSIM。
- 对抗：hinge GAN 或 LSGAN，以稳定性选择。
- 若判别器不稳定则加入特征匹配。
- 验证门禁通过前不声称质量。

## 7) 训练风险登记

- 模式坍塌：判别器胜出或生成器产生重复纹理。
- 幻觉：逼真散斑但相干结构错误。
- 散斑真实性改善而 DAS 保真度下降。
- Patch 级成功但拼接/全卷失败。
- 代理指标改善而人类审查失败。

每次运行必须在 `verdict.md` 中记录这些风险。

## 8) 训练前须完成的动作

1. 最终确定 `docs/RUNBOOK.md`。
2. 创建一个 cGAN 实验文件夹和模板。
3. 审计现有代码中可复用的模块和不可移动的文件。
4. 审查通过后，写一个最小 cGAN smoke-test 实现。
5. Smoke test 不是正式实验，不能解释为质量进展。
