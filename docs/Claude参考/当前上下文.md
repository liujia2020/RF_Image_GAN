## 最近两周发生了什么（2026-06-05 ~ 06-12）

1. **坏 cache 发现**：诊断确认旧 fp16 cache 在 NTFS 盘满时写入静默失败（idx=0 NaN, idx=700 全零），原始 H5 完好。
2. **全盘重组**：四盘重新分区格式化，管线数据统一按 patch 尺寸组织（`rf_pipeline/64x32x32/`）。
3. **fp16 溢出诊断**：全量 1500 扫描发现 label 192/1500、baseline 377/1500 溢出。根因：normalize=False，scale 只存不用。
4. **scale 修复**：normalize=True，三字段同除 scale。Codex 改两端代码，Proma 独立交叉验证通过。
5. **文档体系重构**：统一模板（来源→目的→方法→流程→⚠️踩坑），三方文档分类（原则/Claude/Codex/笔记）。
6. **struct 归一化**：Phase2a v0 发现 struct:adv=43,000:1 量纲失衡。实现 label_mean_envelope 归一化（s = mean(|env(label)|) + 1e-8），数学上 struct_new = struct_old/s。Proma 独立验证确认等价性（max rel_diff 1.08e-7）。
7. **Phase 2a normstruct v1 训练完成**：50 epoch 零 NaN，struct→O(1)。但 carrier（lambda=0.5）未经归一化，占 G_total 99.9%。D_fake_score 从 epoch 3 起卡 0.500。pred_SNR 持续下降。
8. **实验目录重组**：去掉 runs/ 中间层，四段式（01_config/02_train/03_validate/04_proma_verify），Proma 验证脚本迁入 04。
9. **Phase 2a v2 关 carrier 消融实验**：lambda_carrier=0，只用 adv+struct。19 epoch 中止。struct:adv=1:1 比例完美但 G 几乎不学（G_struct 仅降 1.4%）。三实验横向对比展示因果链。
10. **v2 后续三方分析（Claude-Proma-用户）**：Claude 挑战 Proma 的初步结论——v2 只证明"当前坏判别器下 carrier 不可去掉"，不能证明 carrier 本身不可替代。核心病根可能是对抗机制三轮从未生效（D_fake 永远 0.50, D_real=0.73）。Proma 承认逻辑漏洞并接受 Claude 的修正。用户提出 log 压缩观察，引发讨论后确认：线性除标量归一化对复数数据比 log 压缩更合适，不需要整体换压缩空间。用户明确最终目标 B-mode（复数 RF 非必需）。三方收敛：carrier 归一化 + 三损失 1:1:0.25 + 判别器不动，建立干净基线让对抗问题无所遁形。
11. **Phase 2a v3 carrier 归一化干净基线**：25 epoch 完成（原计划 50）。carrier 归一化正确（Proma 独立验证 max rel_diff 8.27e-8），三损失全部 O(1) 无主导项。对抗依然空转（D_fake=0.50, D_real=0.73, G_adv=1.0）。铁证：损失量级永久排除，病根在判别器。Claude 建议先做低成本判别器诊断（Proma 读代码+日志），再精准改，不盲动。同时抛出战略问题：是否继续攻坚对抗+复数 RF 路线，还是回到 B-mode/包络空间验证可行性。
12. **路线转向：文献调研揭示三条致命差异**（2026-06-09）：Claude 搜索 RF→超声成像文献，发现我们和主流做法在训练空间（复数 vs B-mode）、主力损失（adv 主导 vs L1/SSIM 主导）、对抗角色（核心 vs 配角）上完全相反。决定放弃"复数空间+对抗攻坚"，转向"B-mode 空间 + L1+3D-SSIM 纯监督为主、先不用对抗"。输入仍是 3 角度 raw RF（端到端不变），只改输出表示。
13. **B-mode GT 离线转换 + Proma 验证 PASS**（2026-06-09~10）：B-mode 五步标准确定（包络→除全局 REF→20log10→截断[-60,0]dB→映射[0,1]）。全局 REF 选 64407.58（稳健分位数，非绝对 max）。Codex 转 1500 个复数 label，Proma 独立验证 1500/1500 一致（max err 2.44e-4 = fp16 极限）。转换 1.8 秒。phantom 偏暗（均值 0.40）是全局参照的预期结果，本轮接受。
14. **MS-SSIM 尺寸坑发现**（2026-06-10）：数据 [64,32,32] 最小边 32，标准 5 尺度 MS-SSIM 需要 ≥160。改为单尺度 3D SSIM（window=7）。损失：loss = 0.84*(1-SSIM3D) + 0.16*L1。
15. **第十八工作单元发出**（2026-06-10）：网络输出单通道 B-mode [1,64,32,32] + sigmoid，纯监督 L1+3D-SSIM，无对抗无判别器，50 epoch。等 Codex 结果——新路线第一次见真章。
16. **文档整合**（2026-06-10）：Proma Agent 将路线转向全程（10 段对话）整合进四份核心文档。
17. **第十八工作单元：TinyBModeRFNet 失败**（2026-06-10~11）：260K 参数，pred=灰雾（mean 0.528），感受野仅 5 体素，严重欠拟合。诊断：架构太弱，换 U-Net。
18. **Light3DUNet 实现规格**（2026-06-11）：Claude/Proma 联合设计 ~2.11M 参数 3D U-Net：3级 encoder-decoder + 跳跃连接，各向异性下采样，BN momentum=0.9，output bias=-2.0 防灰雾。
19. **第十九工作单元：Light3DUNet 训练完成**（2026-06-11~12）：50 epoch 零 NaN/Inf。Train SSIM 0.107→0.400（+273%），pred 从灰雾→有结构。pred 显著脱离 baseline（val_pred_baseline_l1 -40%）。但：过拟合（train/val SSIM 4.4:1）+ oversmooth（pred 偏糊、边界抹圆）。换架构验证成功，纯 RF 到第一个优化关口。
20. **方法论教训：权威锚定**（2026-06-12）：Claude 第一次判读被 Hy-PCF 论文锚定，过早下"纯 RF 到顶、转双输入"的结论。用户反问后承认偏差——文献该是灵感库而非判决书。纯 RF 没到天花板，过拟合和 oversmooth 都有标准解法且都还没试。发现 #17。
21. **第二十工作单元：B-mode + 对抗 smoke — 对抗终于通电**（2026-06-12~13）：新增 3D 条件判别器 `BMode3DPatchDiscriminator`（1.49M）+ B-mode 对抗损失（lambda_adv=0.1），10 epoch smoke。Proma 5/5 PASS。D_real=0.665 > D_fake=0.573，D_fake 不再死在 0.50。train pred 长出 speckle 纹理（phantom 从灰团变斑驳）。对抗在 B-mode 空间终于通电——Phase 2a 四轮空转的根本原因不是判别器容量、是训练空间（复数 vs B-mode）+ 判别器维度（2D vs 3D）。
22. **H1 vs H4 裁决**（2026-06-13）：同样的输入、同样的网络，只加对抗→speckle 长出来。H1（损失抹平）坐实——3 角度信息够，L1/SSIM 把它抹平了。H4（信息不足、需双输入）被严重削弱。
23. **第二十一工作单元：对抗正式 50-epoch run**（2026-06-13）：e42 触发假红线——evalfixed D 塌向 0.50，但 train 模式 D 健康对抗（gap 0.105→0.180）。根因：生成器 BN running stats 失稳（running var 12,827→36,997），对抗+小batch+G漂移→eval模式被拖垮。同时重大正面信号：e25 val phantom speckle 统计已匹配 gt（pred_std=0.093 vs gt_std=0.093），三类 val pred_std 全贴上 gt_std。对抗比之前以为的更成功。
24. **Proma 假红线诊断 + restore_scale 坑**（2026-06-13）：四模式交叉表坐实 train/eval 脱节。挖出 Proma 上轮 ~0.14 偏移根因——独立脚本漏 restore_scale（baseline 被压全零，D 条件通道废）。修正后完美复现。教训：任何独立读 cache 的脚本必须复现训练的 ×scale 还原。
25. **第二十二工作单元：修假红线重跑，50 epoch PASS**（2026-06-14）：红线基准 evalfixed→train，唯一改动。Proma 6/6 PASS，且发现 evalfixed e21 就穿零——旧红线会误杀健康 run。Train 对抗全程健康（D gap 0.109→0.184）。Speckle 统计全面匹配 gt：e50 val phantom mean 0.452/0.451、std 0.118/0.113、SNR 3.95/4.04（eval 模式算的）。H1 路线成功硬量化证据。Val SSIM 降（0.108→0.073）预期内。下一步：Claude 等 triplet 图判 eval-G 视觉质量→进 03_validate（对抗线首次人眼终审）or 先修 BN→GroupNorm。
