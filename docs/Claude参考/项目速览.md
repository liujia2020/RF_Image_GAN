# 项目速览

> 给 Claude 快速进入状态。详情见 `项目笔记/01_项目概述.md`。

## 一句话

用条件 GAN 从 3 角度 RF 预测 33 角度 DAS 画质。3 角度的采集时间，33 角度的画质。

## 物理背景

- **探头**：RC6gV RCA (128+128 阵元，6MHz，25.6mm)，Verasonics Vantage 256 平台
- **模式**：OPW 正交平面波，RC+CR 互补消除各向异性
- **网格**：128×128×1024 voxels，轴向 0.0362mm，横向 0.2mm（1:5.5 各向异性）
- **声速**：1540 m/s | **采样率**：25 MHz

## 数据管线

```
.mat 原始采集 → 时延对齐 → DAS重建 → Patch裁剪 → HDF5 → fp16 cache → 训练
  302个           MATLAB        3/33角度   64×32×32   1500个   ext4 NVMe
```

- **input**：3 角度 RF [1536,64,32,32]
- **label**：33 角度 DAS [2,64,32,32]
- **baseline**：3 角度 DAS [2,64,32,32]

## 盘位

```
rf_pipeline/   NVMe ext4  训练管线（01_mat→02_h5→03_cache）
rf_project/    HDD        代码+文档
rf_archive/    HDD        .mat原始归档
rf_backup/     USB        冷备份
```

## 技术路线

- **回归模型**（已冻结）：代理指标改善，人眼验证失败（散斑 mush、线靶丢失）。根因：L1 收敛到条件均值。
- **cGAN 当前主线**：生成器 + 2D PatchGAN 判别器。损失 = 对抗 + 结构保真 + 载波约束。
- **Phase 2a**：验证 loss 设计不崩（被 cache 问题阻断，修复后待恢复）
