## 任务A: TinyBModeRFNet 瓶颈诊断

### 完整结构

\\\
Conv3d(1536→64, k1×1×1, s1) + BN + LeakyReLU(0.1)     ← 入口: 逐体素线性投影, 98K参数 (37%)
Conv3d(64→64,  k3×3×3, s1) + BN + LeakyReLU(0.1)     ← 111K参数 (42%)
Conv3d(64→32,  k3×3×3, s1) + BN + LeakyReLU(0.1)     ← 55K参数  (21%)
Conv3d(32→1,   k1×1×1, s1) + sigmoid                    ← 33参数, 零初始化
\\\

总参数量: 264,705. 无下采样, 无上采样, 无跳跃连接, 无残差连接.

### 感受野

k1→k3→k3→k1 堆叠: 有效感受野 = 5×5×5 voxels.
在 Z=64 轴向只能看到 7.8% 的深度; 在 X=Y=32 横向只能看到 16% 的宽度.
**无法捕获任何超过 5 体素的结构.**

### 训练证据

| 指标 | epoch 1 | epoch 50 | 方向 |
|------|---------|----------|------|
| train SSIM | 0.131 | 0.267 | 缓慢上升 |
| **val SSIM** | 0.138 | **0.098** | **下降 (过拟合)** |
| pred_mean | 0.526 | 0.528 | 几乎不变 (输出灰雾均值) |
| pred_baseline_l1 | 0.150 | 0.144 | 几乎不变 (未脱离 baseline) |
| pred初始化 | min=max=mean=0.50 | — | 零初始化 → sigmoid(0)=0.5 |

### 五重瓶颈

1. **入口信息压缩**: 1536通道 RF → 64通道 仅用 1×1×1 卷积. 每个输出体素只是同一位置 1536 个输入值的 64 种线性组合 —— 无跨体素 RF 通道混合, 相当于单个体素的" 可学习波束合成\挤在 64 维里.
2. **无层次特征**: 无池化 → 感受野只有5体素 → 无法建模大尺度解剖结构.
3. **无跳跃连接**: 所有信息必须穿过 64→64→32 窄瓶颈, 丢失空间细节.
4. **容量不足**: 26万参数处理 100M 输入值 (1536×64×32×32). 严重欠参数化.
5. **零初始化从均值出发**: sigmoid(0)=0.5, 所有像素从同一灰值开始, 网络必须\雕刻\出图像 —— 比从噪声出发难得多.

一句话: **网络等于一个 5体素感受野的浅层滤波器, 只能学到\全局平均灰雾\**. 增大容量(更多通道/更深)而不加编码-解码结构, 无法解决感受野问题.

## 任务B: 替换架构候选方案

### 共同约束

- 输入: [B, 1536, 64, 32, 32] (RF通道数据, 非图像通道)
- 输出: [B, 1, 64, 32, 32] (B-mode 图像, sigmoid → [0,1])
- 体积: 64×32×32, 最小边32 → 最多3次 2×下采样 (32→16→8→4)
- 显存: 当前峰值2.4GB, 可承受4-6GB (RTX 4060/5060 8GB)
- Batch: 3 (三类各1)
- 入口降维: 必须将 1536 压缩到合理通道数, 1×1×1 conv 是唯一可行的\逐体素学习波束合成\方式

### 候选1: 轻量 3D U-Net (保守首选)

**结构**:
\\\
入口: Conv3d(1536→64, k1) + BN + ReLU
编码器 3级:
 L1: [Conv3d(64→96,k3)+BN+ReLU]×2 → MaxPool(2) → 32×16×16
 L2: [Conv3d(96→128,k3)+BN+ReLU]×2 → MaxPool(2) → 16×8×8
 L3: [Conv3d(128→192,k3)+BN+ReLU]×2 → MaxPool(2) → 8×4×4 (瓶颈)
解码器 3级:
 L3': UpConv(192→128) + skip(L2) → [Conv3d(256→128,k3)]×2
 L2': UpConv(128→96) + skip(L1) → [Conv3d(192→96,k3)]×2
 L1': UpConv(96→64) → [Conv3d(128→64,k3)]×2
输出: Conv3d(64→1, k1) + sigmoid
\\\

| 属性 | 值 |
|------|-----|
| 参数量 | ~1.5-2M |
| 显存 (batch=3) | ~3-4 GB (可承受) |
| 感受野 | 编码末端覆盖全卷 (8×4×4瓶颈+上采样) |
| 优势 | 层次特征, 跳跃连接保细节, 实现简单, U-Net是医学图像重建最成熟的架构 |
| 风险 | MaxPool 可能损失散斑纹理; 32边只能下采样3次, 感受野刚好够 |
| 文献契合 | 3D U-Net (Çiçek 2016) 是体积医学图像的事实标准; 在超声重建中有多个成功先例 |

### 候选2: 3D 残差 U-Net (更强, 稍复杂)

**改动** (相对候选1):
- 每个编码/解码层的双卷积改为 **残差块**: Conv3d→BN→ReLU→Conv3d→BN + 恒等跳跃
- 瓶颈深度加到 256 (4×4×4)
- 可选: 在入口后加一个 1×1→128 的扩张层 (1536→128 via k1, 更宽的\学习波束合成\)

| 属性 | 值 |
|------|-----|
| 参数量 | ~3-5M |
| 显存 (batch=3) | ~4-5 GB |
| 优势 | 残差改善梯度流, 更深的瓶颈有更强表达力, 对训练不稳定更鲁棒 |
| 风险 | 参数量增大 → 小数据集 (1050 train) 可能过拟合; 需要 careful 正则化 (weight decay, dropout?) |
| 文献契合 | ResUNet 是 U-Net 最广泛采纳的改进 |

### 候选3: 混合 1D+3D (创新的入口处理)

**思路**: 将 1536 通道 RF 入口处理从\一个 1×1 conv\升级为\1D 通道编码器 + 3D 空间编码-解码\

\\\
第1阶段 (1D 通道降维):
 1536 → 分层处理:
 - 128阵元 × 3角度 × 4IQ = 1536
 - 重排为 [3角度, 128阵元, 4IQ] × [64,Z,32,X,32,Y]
 - 每角度独立: Conv2d(128×4→32, k1) in channel-axis → [B, 96, 64, 32, 32]
 - 或: 简单的 1536→128 via 1×1 conv (候选1/2已够用)
第2阶段 (3D U-Net, 同候选1):
 96(or 128) → 3级编码-解码 → 1
\\\

| 属性 | 值 |
|------|-----|
| 参数量 | ~2-3M |
| 显存 | ~4-5 GB |
| 优势 | 利用 RF 的物理结构 (阵元×角度), 可能有更好的物理先验 |
| 风险 | **实现复杂**, 需要重排输入张量; 1D处理可能丢失阵元间空间关系; 收益不确定 |
| 文献契合 | 弱. 多数 RF→图像 工作直接展平通道用 1×1 conv (你的 Tiny 和 BINN 都这样做) |

### 三方案对比

| | 候选1: 轻量3D UNet | 候选2: 残差3D UNet | 候选3: 混合1D+3D |
|---|---|---|---|
| 参数量 | 1.5-2M | 3-5M | 2-3M |
| 显存 | 3-4 GB | 4-5 GB | 4-5 GB |
| 实现复杂度 | 低 | 中 | 高 |
| 文献支持 | 强 | 强 | 弱 |
| 过拟合风险 | 低 | 中 | 中 |
| 入口创新 | 无 | 可选128宽 | 有 (可能不重要) |
| **推荐** | **首选** | 备选 | 暂不推荐 |

### 我的倾向: 候选1 (轻量 3D U-Net)

理由:
1. **解决 Tiny 的核心瓶颈最直接**: 加入层次编码-解码 → 感受野覆盖全卷; 加入跳跃连接 → 保留空间细节; 增加参数到1.5M → 足够的容量.
2. **风险最低**: U-Net 是医学图像重建的事实标准, 3D U-Net 在超声体积重建中有多个先例. 无需发明新结构.
3. **实现简单**: Codex 可用 pytorch 标准组件 (Conv3d, MaxPool3d, ConvTranspose3d 或 Upsample+Conv) 直接搭建. 不需要自定义入口处理.
4. **内存安全**: 3-4GB 峰值远低于 8GB 显卡上限, 留足够余量.
5. **后续可迭代**: 若 U-Net 基线起作用但不够好 → 升级为候选2 (加残差). 若需要更大感受野 → 加 dilation. 层次清晰, 每次只改一个变量.

若不收敛 (概率低但可能): 备选切换到候选2 (残差块 → 更好的梯度流).

### 实现注意事项 (给 Codex)

- **入口 1×1 conv**: 保留, 它是 \可学习波束合成\ 的关键. 1536→64 已是合理起点.
- **下采样**: MaxPool(2) 或 Conv(s=2). 注意 32 这个边 → 最多 2×→16→8, 加一次 32→16→8→4 共3次.
 Z=64 可以多下一次 (64→32→16→8→4) 但保持 XY 对齐更简单.
 建议统一 2×2×2 池化, 3级: (64,32,32)→(32,16,16)→(16,8,8)→(8,4,4).
- **不零初始化最后一层**: 用 Xavier/Kaiming 正常初始化, 避免 sigmoid(0)=0.5 的\灰雾起点\.
- **可选**: 将 baseline (3角度 B-mode) 作为第二个输入通道 concatenate 到入口, 提供低质量参考 —— 类似 U-Net 多模态输入, 可能加速收敛.
